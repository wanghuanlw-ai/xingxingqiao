# 星星桥

基于语料库的孤独症儿童分级阅读干预研究原型。

星星桥是一个面向家长与特教老师的离线可交互网站，围绕“找到孩子愿意读、也读得懂的那一页”展开，包含分级评估、分级书架、逐页阅读、陪读指南与“星星伴读”智能体。

## 功能

- 9 题非诊断式阅读画像评估
- 兴趣与难度双轴书目推荐
- 四维文本复杂度提示
- 汉字字频与分级标准辅助判断
- 逐句朗读、低刺激与高对比阅读模式
- 基于本地规则的“星星伴读”对话智能体

## 运行

这是一个纯静态站点，无需安装依赖。直接用浏览器打开 `index.html` 即可。

## 数据来源

- Jun Da 汉字字频表
- 国家教育研究院汉字分级标准检索系统

## 说明

本项目为研究原型，不构成医学或教育诊断。
